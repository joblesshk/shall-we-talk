构建、权限和签名配置见 [配置说明](../docs/CONFIGURATION.md)，快捷指令见 [Shortcuts](../docs/SHORTCUTS.md)。请使用自己的供应商凭据；仓库不提供私有服务或签名身份。

## 操作按钮的后台可唤醒前提

系统后台执行受应用生命周期、麦克风权限和系统调度约束。从多任务界面强制退出 App 后，不能承诺操作按钮或快捷指令仍可后台开始录音；请先手动重新打开 App 并授予所需权限。后台动作返回文字不等于已经插入其他输入法的输入框，需使用条件复制动作并手动粘贴。

会议快捷指令会打开 App，第一次开始、再次停止录音。真机锁屏、后台持续录音和宿主输入框行为需要分别验收，模拟器构建不替代真机验收。
