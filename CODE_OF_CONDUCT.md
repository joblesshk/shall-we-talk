# Contributor conduct

Keep technical discussion respectful, specific and evidence-based. Harassment, threats, discrimination and publication of another person’s private information are unacceptable. Do not post recordings, credentials or identifying diagnostics without the relevant person’s permission.

Maintainers may edit or remove harmful content and restrict participation. Report sensitive conduct concerns privately through an existing maintainer contact; do not create a public issue containing personal details. This repository currently has no dedicated public reporting address.
