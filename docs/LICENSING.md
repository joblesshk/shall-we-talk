## Why GPLv3

The project already ships GPL-3.0-only Rime Ice dictionaries and a GPL transformation tool. Using GPLv3 for the original application provides a consistent copyleft direction without weakening the existing component terms. It permits commercial use and redistribution, while requiring covered distributed derivatives to retain the same freedoms. This is a project choice, not a claim that merely storing any GPL data beside code automatically determines the code's license.

MIT would allow proprietary derivatives of original code but would not remove GPL obligations on the bundled resources. Apache-2.0 is GPLv3-compatible, but likewise would not convert those resources to permissive licensing. AGPL adds a network-interaction provision that is not the primary need of these native clients. Version 3 only aligns the chosen grant with the pinned dictionary license; no permission to use an unspecified future GPL version is implied.
